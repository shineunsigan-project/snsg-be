# 임시 파일

작업 중 만드는 로그·중간 산출물·임시 스크립트는 **세션 스크래치패드**에 둔다.

```
C:\Users\ks\AppData\Local\Temp\claude\<프로젝트>\<세션id>\scratchpad\
```

세션별로 격리되어 있고 권한 프롬프트 없이 쓸 수 있다. `/tmp`나 시스템 임시 디렉터리에는 만들지 않는다. 세션과 무관하게 쌓여 누가 언제 만든 것인지 알 수 없게 된다.

**프로젝트와 워크트리 안에는 만들지 않는다.** 이유는 둘이다.

- `.claude/skills/implement/SKILL.md`가 `git add -A`로 스테이징한다. 남아 있으면 그대로 커밋 후보에 섞인다.
- dirty한 워크트리는 `git worktree remove`가 거부한다. `.claude/rules/git-workflow.md` 5번 단계에서 막힌다.

**`*.log`는 `.gitignore` 대상이라 `git status`에 보이지 않는다.** 워크트리에 로그를 만들면 눈에 띄지 않게 쌓인다. `.sql`·`.txt`·`.md` 스크래치 파일은 `git status`에 뜨지만, 보이지 않는 쪽이 더 위험하다.

## 언제 정리하는가

- **단발로 끝나는 작업**(질문에 답하기, 조회, 로그 확인): 그 작업이 끝날 때 지운다.
- **`/task` 파이프라인**: `git add`로 스테이징하기 **전에** 워크트리에서 치운다. 스테이징한 뒤에 발견하면 이미 커밋 후보에 들어가 있다.
- **프로세스를 띄워두고 계속 쓰는 동안**(앱, ngrok): 로그는 아직 필요하므로 남긴다. 프로세스를 멈출 때 함께 지운다.

## 지우지 않는 것

gitignore 대상이라고 임시 파일이 아니다. 아래는 지우면 작업이나 데이터가 깨진다.

| 경로 | 왜 필요한가 |
|---|---|
| `snsg/.env` | 워크트리마다 복사해야 빌드·테스트가 돈다 (`.claude/rules/git-workflow.md`) |
| `snsg/build/`, `snsg/.gradle/` | 빌드 산출물과 Gradle 캐시. 지우면 다음 빌드가 처음부터 돈다 |
| `snsg/uploads/` | `.env`의 `FILE_STORAGE_DIRECTORY`가 가리키는 로컬 파일 저장소다. `profiles/` 하위에 실제 업로드된 프로필 사진이 있다 |

- **사용자가 만든 파일은 지우지 않는다.** 내가 만든 것만 치운다.
- **다른 세션의 스크래치패드를 지우지 않는다.** 그 세션이 아직 쓰고 있을 수 있다.
